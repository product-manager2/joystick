# Pip app commands

Pip can discover the current command catalog with `listAgentCommands`, read current app state with `queryAgentApp`, and run commands with `executeAgentCommand`. The server binds the actor to the authenticated sender of the private agent message. Pip cannot choose another user ID. Game commands pass through the shared `applyGameCommand` core with the same membership, owner, stage, task, review, wallet, and idempotency rules as the UI. See [game-actions.md](game-actions.md) for payloads and state rules.

The catalog includes all `GAME_ACTIONS` plus room messages and read receipts, work-run creation/decisions/cancellation, artifact and credit exports, and navigation. `queryAgentApp` supports `missions`, `mission`, `stage`, `plan`, `quest`, `profile`, `people`, `rooms`, `messages`, `notifications`, `invites`, `wallet`, `policy`, `trust`, `runs`, `run`, `artifact`, and `credits.csv`. List views are paged to at most 50 items; messages use their sequence cursor. Use `query` as the run cursor for `runs`.

Game action request IDs are UUIDs. The game service stores each action's result in the same transaction as its effects. Retrying the same action and ID returns the same created entity ID; changing the action or payload with that ID returns `idempotency_conflict`. The agent worker derives a stable request ID from each tool use. Chat sends use the same ID as their client ID. Work runs keep their existing admission limits and request ID semantics.

`artifact.download` and `credits.export` return a browser download handoff. `ui.open` and `passkeys.manage` return navigation handoffs. The browser completes passkey creation, verification, reauthentication, recovery, and local file downloads with the person's device. The command bridge does not handle credentials, recovery codes, session cookies, or file picker contents. A navigation handoff reports that a screen is ready to open, not that the person completed the device action. Credit exports can be CSV or JSON; credits and payouts remain labeled test simulations.
