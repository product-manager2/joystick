## Additional flows

- **Onboarding mission selection:** `onboarding.js:missionStep` restores topic filters, multi-selection and role-fit counts; `finishOnboarding` persists joins and profile choices. Current matching counts open tasks, so dependency/stage-aware fit remains less precise than Play eligibility.
- **Plan/task creation:** the same `creation.js` conversation supports contextual idea chips, real agent drafts, editable proposals and explicit confirmation. Task options include role, size, plan, parent/dependencies, decision choices and reward. Source handlers connect mission/plan/task creation to backend actions rather than prototype mutations.
- **Contextual agent help:** stage and plan Ask composers create private context; group rooms remain separate actions. Context prompts can start planning/task drafting. The response/run view remains separate from the underlying stage or plan screen.
- **Execution and evidence:** real agent runs, human choices, cancellation, artifact editing/submission, versioned artifacts and independent review are retained. A task's private run appears inside its Chat tab and can be restored from its history; actual room messages remain chronological. Prototype timers, scripted progress, invented reviewer approvals and automatic success are not features to port.
- **Wallet/trust/tools:** ordinary screens no longer repeat demo/example-money notices. Backend test-credit semantics and authorization remain. Wallet actions do not establish real payment rails; declared skills and tool preferences do not establish verification or external connections. Dedicated trust/prize/ledger and learned-agent-memory sheets remain incomplete compared with the prototype.
